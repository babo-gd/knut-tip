# 넛팁 KNUT!P

국립한국교통대학교 충주캠퍼스 학생들이 모은 생활 꿀팁 앱입니다. 도메인특화 AI 수업 3주차 과제로, 2주차에 정규화한 학생 21명의 맛집·생활꿀팁 데이터를 서비스로 만들었습니다.

`app.html` 한 파일에 화면, 데이터, 폰트(경기천년바탕 일부)가 모두 들어 있어서 브라우저로 바로 열 수 있습니다.

## 주요 기능

- 로그인: 계정 유형(학생, 학부모, 교직원, 입학 지원자)을 고르고 이름과 학과를 입력
- 맛집 지도: OpenStreetMap 기반의 실제 충주 지도, 끌기와 확대, 추천 수 핀, 모여 있는 가게 묶음, 화면 안의 가게 카드
- 오늘의 학식: 학생식당, 교직원식당, 생활관(예성) 식단을 요일별로 보기
- 이동, 학교생활(건물별 층 안내 포함), 학업·장학, 진로
- 학업·진로는 학과(2026년 학과 개편 기준)를 고른 뒤에 볼 수 있음

## 폴더

| 경로 | 내용 |
| --- | --- |
| `index.html` | 들어올 때마다 최신 `app.html`을 받아 오는 시작 페이지 |
| `app.html` | 완성된 앱 |
| `scripts/` | 앱을 단계별로 고친 Node 패치 스크립트와 지도·좌표 생성 스크립트 |
| `data/places.json` | 맛집 95곳 (2주차 정규화 데이터) |
| `data/loc.json` | 맛집 좌표 (OSM 가게 이름 일치 또는 도로명 주소 번호로 계산) |
| `data/map.json` | 충주 지도 레이어 (OpenStreetMap에서 추출해 단순화) |
| `data/mt01.json`, `data/mt02.json`, `data/yesung.json` | 2026년 10월 19일~23일 학식 (학교 홈페이지 기준) |

`scripts/`는 작업 기록용입니다. 원래 작업 폴더의 경로(`../web`, `../font`)를 기준으로 작성되어 있어서 이 저장소에서 그대로 실행되지는 않습니다.
